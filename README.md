## 🌟 Overview

**Stark Infotech** is a technology-driven IT company focused on developing innovative software solutions, building intelligent digital products, and providing advanced technology services. This repository houses the company's official web platform.

### ✨ Key Design Pillars

- **Visual Direction:** Deep near-black canvas (`#111111`) with multi-tonal elevated surfaces (`#181818`, `#202020`).
- **Gradient Identity:** Vibrant Pink, Magenta, Coral, and Orange gradient transitions (`#E94F9B` ➔ `#C747A8` ➔ `#FF706C` ➔ `#F6A23B`).
- **Typography:** [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) for bold editorial headlines and [Sora](https://fonts.google.com/specimen/Sora) for body typography.
- **Atmosphere:** Controlled ambient radial reflections (`blur-3xl`, 10–15% opacity) without excessive glows or clutter.
- **3D Sculptural Geometry:** Vector geometric polyhedron centerpiece with specular reflections and orbital telemetry rings.
- **Asymmetrical Editorial Layouts:** Non-generic compositions tailored to each capability.

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- `npm` or `bun`

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/starkinfotech/website.git
cd website
npm install
```

### Development Server

Start the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

Create an optimized, minified production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Linting & Code Quality

Run ESLint to check for code standards and TypeScript conformance:

```bash
npm run lint
```
